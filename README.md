# 🎵 JavaScript Music Player

A simple and responsive **Music Player** built using **HTML, CSS, and JavaScript**. This project provides basic music player functionality, allowing users to play and pause a song, move forward and backward through the track, and control the song using the progress timeline.

---

## 🚀 Features

- ▶️ Play the song
- ⏸️ Pause/stop the song
- ⏮️ Move backward in the song
- ⏭️ Move forward in the song
- 🎚️ Control the song using the progress timeline
- 🎵 Displays the song title
- 👤 Displays the artist name
- 🖼️ Displays the song/artist image
- 📱 Responsive music player interface
- 🎨 Clean and modern user interface
- ⚡ Built using vanilla JavaScript

---

## 🛠️ Technologies Used

- **HTML5** – Structure of the music player
- **CSS3** – Styling, layout, and responsive design
- **JavaScript** – Music controls and player functionality
- **HTML5 Audio API** – Playing and controlling the audio

## 🎮 How It Works

1. Open the music player in your browser.
2. Click the **Play** button to start the song.
3. Click the **Pause** button to pause the song.
4. Use the **Forward** button to move ahead in the track.
5. Use the **Backward** button to move back in the track.
6. Drag or click on the **progress timeline** to move to a specific part of the song.
7. The song title, artist name, and image are displayed on the player.
